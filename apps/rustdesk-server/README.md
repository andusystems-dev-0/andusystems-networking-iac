# rustdesk-server

Self-hosted RustDesk Server OSS (`hbbs` + `hbbr`) deployed to the
networking cluster by the `rustdesk-server` Ansible role. All
manifests are templated by the role — this directory holds no
manifests.

## Components

- `hbbs` — signaling/rendezvous (TCP 21115, TCP/UDP 21116, TCP 21118)
- `hbbr` — relay for fallback when hole punching fails (TCP 21117, TCP 21119)
- `rustdesk-data` PVC (Longhorn) — holds the `id_ed25519` keypair
  generated by `hbbs` on first start

## Access paths

- **LAN** — single MetalLB IP (`vault_rustdesk_lan_ip`) shared by both
  Services via `metallb.universe.tf/allow-shared-ip`. The gaming PC
  reaches this IP via `/etc/hosts` resolution of the relay FQDN.
- **Pangolin overlay** — ClusterIP Services `hbbs` and `hbbr` in the
  `rustdesk-server` namespace, targeted as upstreams by manually
  created Pangolin private resources.
